# Product

## Register

product

## Users

A MacBook user who works with the built-in display and one or more external displays. After an initial manual setup, the user wants known display scaling to be restored automatically without needing to revisit System Settings.

## Product Purpose

Screen Shifter records a display's current scaling profile and restores it when that known display reconnects or the display topology settles. It runs as a local menu-bar utility, leaves unknown displays unchanged, and does not require an account, network access, analytics, or another runtime application.

Success means the user can configure a display once, then rely on the saved profile being applied quietly and predictably.

## Brand Personality

Quiet, precise, predictable.

The setup flow is similar to a macro: record the current setup, then apply the saved setup automatically when the matching condition occurs.

## Anti-references

No specific named anti-references were provided. Avoid attention-demanding UI, repeated prompts after setup, and dashboard-like complexity that makes a background utility feel like a destination app.

## Design Principles

- Stay out of the way after setup.
- Make recording, applying, and resetting states clear and reversible.
- Never change an unknown display without explicit user configuration.
- Use familiar macOS patterns so the utility feels native and dependable.
- Keep local state and automation behavior understandable to the user.

## Accessibility & Inclusion

Follow standard macOS accessibility conventions, including VoiceOver support, keyboard navigation, readable contrast, and reduced-motion handling. No additional user-specific requirements were provided.
